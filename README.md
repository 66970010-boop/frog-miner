## 🎮 游戏简介

一款类似「黄金矿工」玩法的网页小游戏：你扮演 **蛋蛋**（od 厂长的手下），用钩子抓取场景中的 **奶蛙**，在限定时间内达到厂长设定的金额目标即可过关。

- **三种难度**：简单 / 中等 / 困难
- **图鉴收集**：共 11 只奶蛙可收集，每一关都藏着一只稀有小奶蛙
- **厂长系统**：连续空钩会让厂长生气 😠

## 🕹️ 操作方式

| 按键 | 功能 |
| ---- | ---- |
| 空格 / 点击画面 / 手指点按 | 放钩 |
| 再按一次 | 提前收钩 |
| `P` | 暂停 |
| `M` | 静音 |
